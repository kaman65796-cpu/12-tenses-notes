📚 12 Tenses in English

Complete Tense Notes — Affirmative • Negative • Interrogative

1. Present Indefinite Tense

पहचान: ता है, ती है, ते हैं आदि।
Formula: Subject + V1/V1+s/es + Object

Affirmative (+)

Ram goes to Dhata.

राम धाता जाता है।

Negative (-)

Ram does not go to Dhata.

राम धाता नहीं जाता है।

Interrogative (?)

Does Ram go to Dhata?

क्या राम धाता जाता है?

Negative Formula: Subject + do/does + not + V1 + Object
Interrogative: Do/Does + Subject + V1 + Object?

2. Present Continuous Tense

पहचान: रहा है, रही है, रहे हैं आदि।
Formula: Subject + is/am/are + V1-ing + Object

Affirmative (+)

Kunal is reading a book.

कुणाल किताब पढ़ रहा है।

Negative (-)

Kunal is not reading a book.

कुणाल किताब नहीं पढ़ रहा है।

Interrogative (?)

Is Kunal reading a book?

क्या कुणाल किताब पढ़ रहा है?

Negative: Subject + is/am/are + not + V1-ing + Object
Interrogative: Is/Am/Are + Subject + V1-ing + Object?

3. Present Perfect Tense

पहचान: चुका है, चुकी है, चुके हैं आदि।
Formula: Subject + has/have + V3 + Object

Affirmative (+)

Sunil has gone to Ayodhya.

सुनील अयोध्या जा चुका है।

Negative (-)

Sunil has not gone to Ayodhya.

सुनील अयोध्या नहीं गया है।

Interrogative (?)

Has Sunil gone to Ayodhya?

क्या सुनील अयोध्या गया है?

Negative: Subject + has/have + not + V3 + Object
Interrogative: Has/Have + Subject + V3 + Object?

4. Present Perfect Continuous Tense

पहचान: से रहा है, से रही है, से रहे हैं आदि।
Formula: Subject + has/have been + V1-ing + Object + since/for

Affirmative (+)

Ram has been studying for two hours.

राम दो घंटे से पढ़ रहा है।

Negative (-)

Ram has not been studying for two hours.

राम दो घंटे से नहीं पढ़ रहा है।

Interrogative (?)

Has Ram been studying for two hours?

क्या राम दो घंटे से पढ़ रहा है?

5. Past Indefinite Tense

पहचान: गया, गया था, किया, खाया आदि।
Formula: Subject + V2 + Object

Affirmative (+)

Ram went to Dhata.

राम धाता गया।

Negative (-)

Ram did not go to Dhata.

राम धाता नहीं गया।

Interrogative (?)

Did Ram go to Dhata?

क्या राम धाता गया?

6. Past Continuous Tense

पहचान: रहा था, रही थी, रहे थे आदि।
Formula: Subject + was/were + V1-ing + Object

Affirmative (+)

राम किताब पढ़ रहा था।

Negative (-)

Ram was not reading a book.

राम किताब नहीं पढ़ रहा था।

Interrogative (?)

Was Ram reading a book?

क्या राम किताब पढ़ रहा था?

7. Past Perfect Tense

पहचान: चुका था, चुकी थी, चुके थे आदि।
Formula: Subject + had + V3 + Object

Affirmative (+)

Negative (-)

राम ने खाना नहीं खाया था।

Interrogative (?)

क्या राम ने खाना खाया था?

8. Past Perfect Continuous Tense

पहचान: से रहा था, से रही थी, से रहे थे आदि।

9. Future Indefinite Tense

पहचान: गा, गी, गे आदि।
Formula: Subject + will + V1 + Object

Affirmative (+)

राम धाता जाएगा।

Negative (-)

राम धाता नहीं जाएगा।

Interrogative (?)

क्या राम धाता जाएगा?

10. Future Continuous Tense

11. Future Perfect Tense

पहचान: चुका होगा, चुकी होगी, चुके होंगे आदि।
